# Portfolio Site Builder

A Claude skill for building a portfolio website that shows **every side of you**, made for multi-hyphenates and multidisciplinary creatives.

If your work spans strategy, storytelling, community, design, building or more, and one job title never fits, this skill walks Claude through building a site that holds all of it together. It goes from your brief and photos to a live site, a working contact form and a short preview video you can share.

Built by [Mfonobong Charis](https://mfonoongcharis.netlify.app/), from the process of building her own portfolio.

## What it does

The skill takes Claude through seven stages:

1. **Brief.** Your positioning, your "sides", your best work, your photos, and references, including sites that feel too generic or AI-made to you.
2. **Structure.** A site built around your sides, so recruiters and clients can see where you fit. Includes a simpler version for single-discipline portfolios.
3. **Build.** A fast, animated site with an editorial feel that avoids the template look.
4. **Review.** Screenshot checks and focused feedback rounds where only what you ask for changes.
5. **Contact form.** A free Tally form that sends enquiries to your email.
6. **Launch.** Drag-and-drop deployment to Netlify.
7. **Preview video.** A 30–40 second walkthrough and a 10-second teaser for social media.

## Install

### Claude (web, desktop, mobile)
1. Download this repository (green **Code** button, then **Download ZIP**) and unzip it.
2. Zip the `portfolio-site-builder` folder on its own.
3. In Claude, go to **Customize → Skills**, click **+**, then **Create skill → Upload a skill**, and upload that zip.
4. Make sure the skill is switched on. Code execution and file creation need to be on (Settings → Capabilities).

Full instructions: [Use skills in Claude](https://support.claude.com/en/articles/12512180-use-skills-in-claude)

### Claude Code
Copy the `portfolio-site-builder` folder into `~/.claude/skills/`.

## Use it

Start a chat with something like:

> I want to build my portfolio website. I do brand strategy, content and community work. Here are my photos and the projects I want to show.

Claude will start with the brief.
